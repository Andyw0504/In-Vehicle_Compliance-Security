# 学习资源汇总

> 按用途分类。标准原文优先读一手资料，二手解读用来加速理解。

## 标准与法规原文

| 资料 | 获取方式 |
|---|---|
| UN R155 / R156 原文 | UNECE 官网免费下载（WP.29 → Regulations） |
| ISO/SAE 21434 | ISO 官网付费；学校图书馆/公司资料库常有 |
| ISO 24089 / ISO 14229 / ISO 13400 | ISO 官网付费 |
| **GB 44495 / GB 44496（2024 强标）** | 国家标准全文公开系统（公开阅读） |
| GB/T 40855~40861 系列 | 国家标准全文公开系统 |
| 《汽车数据安全管理若干规定（试行）》 | 网信办官网 |
| NHTSA 网络安全最佳实践 | NHTSA 官网（免费，美国版指导） |

## 书籍

**体系/合规**
- 《汽车网络安全》（ISO 21434 中文解读类，任选口碑好的）
- 《智能网联汽车信息安全》/《车联网安全》类教材（入门框架）

**技术**
- 《汽车网络安全攻防》类实战书（CAN/UDS 实操）
- *Automotive Cybersecurity* 系列（Packt/.Springer 有多本）
- 经典白皮书：**Miller & Valasek 网站免费下载全部研究**（2013~2016，必读）

## 在线课程/讲座

- OpenGarages：车辆安全入门教程 + ICSim 靶场（免费）
- Car Hacking Village（DEF CON / 国内各类车联网安全峰会的公开演讲）
- 国内会议：安全车联、AutoCS、Cyber-Security 沙龙类公开视频
