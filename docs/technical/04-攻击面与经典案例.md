# 04 · 攻击面与经典案例

> 通过经典案例建立"攻击者视角"，每个案例都要追问：入口 → 权限提升 → 跨域 → 影响 → 修复。

## 攻击面全景

| 攻击面 | 典型入口 | 威胁场景 |
|---|---|---|
| **TBOX 蜂窝** | 4G/5G 数据、短信 | 远程注入、运营商网络利用 |
| **IVI 车机** | 蓝牙/WiFi/USB/互联 APP | 代码执行 → 提权 → 发总线报文 |
| **RKE/PEPS 钥匙** | 315/433MHz、BLE | 重放、中继(Relay)、滚动码逆向 |
| **OTA** | 升级服务器/升级包 | 篡改、降级、中间人 |
| **OBD-II** | 物理诊断口 | 0x27 解锁、固件提取 |
| **V2X** | PC5 直连 | 伪造消息、位置欺骗 |
| **充电系统** | 充电桩/PLC | 协议层攻击、计费欺骗 |
| **供应链** | 供应商固件/SDK | 后门、弱密钥、共享算法 |

## 经典案例复盘

### 1. Jeep Cherokee（2015，Miller & Valasek）

- **入口**：IVI 联网模块（Sprint 蜂窝网络可达 → 远程任意 IP）
- **链路**：IVI (QNX) 漏洞执行代码 → 经网关 → CAN 发送报文
- **影响**：空调/雨刮/转向/刹车（低速、驻车场景）；引发 **147 万辆召回**
- **修复**：网络隔离补丁；两人随后发布攻击平台公开研究
- **行业意义**：直接推动 R155/21434 立法进程
- **学到**：*远程可达性* 是最危险的攻击面；网关隔离是纵深防御关键

### 2. Tesla（2016~2020，多次 Pwn2Own）

- 攻击路径：浏览器 → 车机 → 网关；后门利用代理服务
- Tesla 的响应体系（OTA 快速修复 + 漏洞赏金）成为行业标杆
- **学到**：OTA 应急能力 = 后生产阶段安全的生命线

### 3. 钥匙重放/中继（RKE）

- 早期固定码：抓包重放直接开门（老款车型）
- 滚动码（KeeLoq 等）：逆向算法或"堵塞+截获+重放"
- **中继攻击（Relay）**：两台设备接力转发射频信号 → 车以为钥匙在旁边 → PEPS 车型无感被开走
- **学到**：物理层信号不等于身份认证；UWB 测距是新一代防御

### 4. CAN 注入通用模式

- 物理接入（OBD/大灯线束）→ 重放车速/挡位报文 → 欺骗仪表/ECU
- 2023 年前后英国多起**无钥匙车辆被盗**与 CAN 注入器有关（前灯接口直连 CAN）
- **学到**：车头外部接口也要纳入攻击面（不只是 OBD）

### 5. 智能座舱/APP 类

- 车主 APP 未授权接口 → 查询/控制他人车辆（多家车企曾出现）
- IVI 蓝牙服务内存破坏 → 车机代码执行
- **学到**：IT 世界的 Web/移动安全问题在车上直接复现，且后果升级

## 威胁建模方法（对一个新攻击面）

1. 画出**完整攻击链**：入口 → 执行 → 横向 → 目标资产
2. 每一环问：认证？授权？加密？完整性？新鲜度？
3. STRIDE 逐类过一遍
4. 用 TARA 打分，输出处置建议
