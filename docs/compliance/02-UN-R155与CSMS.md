# 02 · UN R155 与 CSMS

> R155 全名《关于网络安全和网络安全管理体系的统一规定》。两条主线：**组织层的 CSMS** + **车辆型式的网络安全要求**。

## R155 结构速览

| 部分 | 内容 |
|---|---|
| CSMS 证书 | 组织层认证，由审批机构/其授权方审核，**有效期 3 年**，每年监督审核 |
| 车辆型式（Vehicle Type）要求 | 针对具体车型的风险评估与缓解措施，基于 CSMS 运行出具合规报告 |
| Annex 5 | 威胁目录与缓解措施库（Threats, Vulnerabilities and Mitigations, TVM）结构 |

## CSMS 七大核心要素

1. **组织与治理**
   - 网络安全政策、责任与权限矩阵（管理层承诺是审核硬指标）
   - 网络安全文化：培训、意识、考核
2. **过程与流程**
   - 开发阶段：需求 → 设计 → 实现 → 测试全流程的安全活动（对应 21434）
   - 后生产阶段：漏洞监测、事件响应、OTA 修复流程
3. **风险管理**
   - 全生命周期风险评估（TARA）与处置：规避/缓解/分担/保留
4. **监控**
   - 车队监测、威胁情报（CTI）、漏洞情报（CVE/CNVD 等）
   - **FedR（相关性发现函数）**：判断新漏洞是否影响已上市车型
5. **供应链**
   - 供应商/服务提供商的合同约束、能力评估、联合风险治理
   - 一级二级供应商都要纳入（审核必查供应商管理证据）
6. **事件响应**
   - 响应预案、演练记录、与审批机构的沟通义务（严重事件需报告）
7. **持续改进**
   - 内审、管理评审、纠正措施、指标度量

## 车辆型式合规要点（R155 §7.3）

针对每个车型（含电子电气架构变化）要证明：

- [ ] 完成车型级风险评估（TARA）
- [ ] 风险得到缓解或接受（基于 CSMS 决策）
- [ ] Annex 5 TVM 中相关威胁已识别并采取措施（攻击面：通信信道、OTA、外部接口、诊断口等）
- [ ] 后生产阶段有监控与响应能力支撑
- [ ] 测试与验证证据包（渗透测试报告、模糊测试记录等）

## Annex 5 TVM 威胁清单（示例分组）

| 攻击面 | 典型威胁 |
|---|---|
| 后端服务器 | 服务器漏洞、API 滥用、数据泄露 |
| 通信信道 | 蜂窝/蓝牙/WiFi/V2X 中间人、欺骗、注入 |
| 车辆接口 | OBD 诊断滥用、USB 恶意文件、充电接口 |
| 车内网络 | CAN 报文伪造、DoS、节点提权 |
| OTA | 升级包篡改、降级攻击、签名绕过 |
| 人为因素 | 弱口令、社会工程 |

## 认证流程实操

```
准备(差距分析) → 体系文件建设 → 运行(留记录≥3个月) 
→ 内审+管理评审 → 向审批机构申请 → 文件审查+现场审核 
→ 不符合项整改 → 获证 → 年度监督审核(3年换证)
```

常见不符合项（审核重灾区）：
- 供应商安全能力评估没有记录
- 事件响应流程从未演练过
- FedR 相关性判定无文档
- 培训计划与实际执行对不上
