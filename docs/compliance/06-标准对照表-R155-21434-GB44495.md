# 06 · R155 / ISO 21434 / GB 44495 标准对照表

> 三套体系条款级映射，做差距分析和体系文件时直接查。对照是理解三者的最快方式。

## 总体定位对照

| 维度 | UN R155 | ISO/SAE 21434 | GB 44495-2024 |
|---|---|---|---|
| 性质 | 法规（准入强制） | 标准（工程方法） | 国家强标（准入强制） |
| 管辖 | 缔约方市场（欧盟等） | 全球通用 | 中国 |
| 对象 | 组织(CSMS) + 车型 | 产品全生命周期工程 | 组织管理体系 + 整车技术要求 |
| 生效 | 欧盟新车型 2022.7 / 全部 2024.7 | 2021.8 发布 | **2026.1.1 新车型强制** |
| 认证 | 审批机构 CSMS 证书 + 车型合规报告 | 无认证（符合性作为证据） | 型式批准（指定机构测试+体系核查） |

## 差异与实务要点

1. **颗粒度差异**：R155 讲"要有什么能力"，21434 讲"怎么做"，GB 44495 讲"做到什么程度算合格（可测）"
2. **测试方法差异**：GB 44495 附带官方测试方法（审核时按它测），R155 由审批机构自定，21434 只给工程方法
3. **出口策略**：出口欧盟车 = R155 必须过，同时国内销售满足 GB —— **一套工程实践（按 21434 做）满足两个法规**，这就是 21434 是"杠杆"的原因
4. **文件复用**：TARA 报告 / 渗透测试报告 / 漏洞台账可同时作为三家要求的证据，注意格式里把各法规条款号标注上
