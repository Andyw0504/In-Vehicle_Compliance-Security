# 漏洞台账（Vulnerability Ledger）

> 车队/车型全生命周期漏洞跟踪，对应 R155 FedR 与 21434 §12 运维要求。配合 `docs/compliance/05-合规落地实践.md` 使用。

## 台账字段说明

| 字段 | 说明 |
|---|---|
| ID | VULN-YYYY-XXX |
| 来源 | 自测/外委/情报(CVE/CNVD)/赏金/监管通报 |
| FedR 判定 | 相关(影响在售车型)/不相关(理由) |
| 状态 | 发现→评估→修复中→已修复→已复测→关闭 |
